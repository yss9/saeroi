# [공지] 사업자 회원가입이 막혀 있습니다 — 카카오 REST API 키 필요 (2026-09-11)

작성: 6번(인프라) · 대상: 전 파트, 특히 회원가입 담당

## 무엇이 문제인가

사업자(업체) 회원가입 시 주소를 좌표로 변환하는 카카오 Geocoding API를 쓰는데,
`KAKAO_REST_API_KEY`가 운영/`test` 어디에도 설정된 적이 없습니다. 백엔드는 이 키가
없으면 **좌표 없는 업체가 저장되지 않도록 사업자 회원가입·주소 변경 자체를 의도적으로
거절**하도록 설계돼 있습니다(`KakaoGeocodingProperties.isConfigured()`).

`/test/` 스택에서 사업자 회원가입을 테스트하다가 발견했고, 운영도 같은 상태입니다 —
지금 사업자 회원가입은 운영에서도 안 됩니다.

## 지금까지 한 것

`docker-compose.yml`(운영)·`docker-compose.test.yml`(test)에 `KAKAO_REST_API_KEY` 전달
경로만 추가했습니다. **실제 키 값은 인프라가 만들어낼 수 없습니다.**

## 필요한 것

[카카오 디벨로퍼스](https://developers.kakao.com)에서 앱을 만들고 REST API 키를
발급받아야 합니다. 담당자 정해지면 값을 EC2 `.env`(운영)·`.env.test`(test) 양쪽의
`KAKAO_REST_API_KEY`에 채워 넣고 backend를 재기동하면 됩니다.

이 키를 누가 발급받을지, 카카오 계정(개인/팀) 중 어디로 만들지 정해서 알려주세요.
정해지기 전까지 **사업자 회원가입은 운영·test 둘 다 불가능한 상태**입니다.
